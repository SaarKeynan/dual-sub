Install a French system voice

Firefox supplies DualSub with voices installed by your operating system. DualSub cannot install an operating-system component itself, but setup usually takes only a minute.

WindowsmacOSLinux

Windows 11 or 10

  1. Open Settings → Time & language → Speech.
  2. Under Manage voices, choose Add voices.
  3. Install French (France), French (Canada), or your preferred French voice.
  4. Completely close and reopen Firefox, then use DualSub’s pronunciation preview.

macOS

  1. Open System Settings → Accessibility → Read & Speak.
  2. Open System Voice, use the information button to show more voices, and download a French voice.
  3. Restart Firefox and preview the voice in DualSub.

Linux

Install a French-capable speech engine through your distribution, commonly Speech Dispatcher with eSpeak NG, then restart Firefox. Package names and Firefox voice support vary by distribution.

If a voice still does not appear, restart the operating system once and check that the voice can speak French in another system application.
